Windows PC Server Setup Guide (One Shared Office PC for All Staff)

Do we need one Python server per person?
No! Run ONE shared Python server on a single always-on office Windows PC. FastAPI handles multiple concurrent staff requests cleanly and uses per-client folder locks so two users can work at the same time without conflicts. All generated packets are automatically saved to the shared Clients\LastName,FirstName\ folder on the office PC (syncing via SynologyDrive) and returned encrypted as a downloadable .zip to whichever staff member clicked Generate.

Automated One-Click Setup on the Host Windows PC:

  1. Install Python 3.12+ from python.org (check "Add python.exe to PATH").
  2. Double-click Start Shared Petition Server (Cloudflare Tunnel).bat in your Wart folder.
  3. The script automatically:
    • Installs any missing Python PDF libraries (pymupdf, reportlab, fastapi, uvicorn)
    • Generates & displays your private Relay Secret (saved in petition_app\data\settings.json)
    • Starts the multi-user Python server on http://127.0.0.1:8765
    • Downloads cloudflared.exe automatically and opens an encrypted HTTPS tunnel
  4. One-Time Cloudflare Setup for Zero-Domain Auto-Registration (Recommended):
    • Your wrangler.toml already binds KV Namespace PETITION_CONFIG automatically on deploy!
    • In your Worker → Settings → Variables and Secrets, add encrypted secrets PETITION_ENCRYPTION_KEY (your firm E2E passphrase) and PYTHON_RELAY_SECRET (printed by the Windows launcher).
    • On first launch, enter your Cloudflare Worker URL when prompted (saved to petition_app\data\cloudflare_worker_url.txt). From then on, every time the office PC restarts, the launcher automatically registers the new Quick Tunnel URL in Cloudflare KV — all staff connect automatically with zero copy-paste!
  5. Optional (Windows Auto-Start on Boot): Press Win + R, type shell:startup, and drop a shortcut to Start Shared Petition Server (Cloudflare Tunnel).bat in that folder.
